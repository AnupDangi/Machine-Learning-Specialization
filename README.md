## Run Locally

### Clone the Repository
```bash
  git clone https://github.com/AnupDangi/Machine-Learning-Specialization.git
```

### Navigate to the Project Directory
```bash
  cd Supervised Machine Learning: Regression and Classification
```

### Install Required Libraries
Ensure you have the necessary libraries installed, such as pandas, numpy, matplotlib, and scikit-learn. Below is an example to install pandas:
```bash
  pip install pandas
```
Install other libraries similarly.

### Run the Jupyter Notebook
Open the Jupyter Notebook and execute each code block step by step:
```bash
  Ctrl+Enter
```
This will allow you to run and understand the implemented concepts interactively.
